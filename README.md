One sentence that could have replaced an entire pointless meeting,
written by a program to `/output/entry.txt`.

The entry is a single line, in plain office voice — the meeting
deflated twice, first into an email, then into nothing at all:

> This meeting could have been an email, and the email could have been a shrug.

## Run

```sh
python3 main.py
```

This validates the entry (single line, 1–200 characters, UTF-8),
writes it to `/output/entry.txt`, then re-reads the file and
validates it again.

## Entry

See `ENTRY` in `main.py`; running the program prints its character
count and writes it out.
